- EA station search is CASE-SENSITIVE (`search=colwick` returns nothing, `Colwick` works; every word must start with a capital). The client title-cases a search term only when it was typed all-lowercase, so "colwick" works but "OBH" is left alone. Not perfect (e.g. "bourton-on-the-water") but avoids a second EA request.

- Cache: 5 min, one file per URL in `ea.cache_dir` (default system temp dir), written via temp file + rename. Failures and 404s are never cached.
Problem & fix: First run returned 500 for every EA call: `curl_close()` is deprecated in PHP 8.5 and the project's error handler turns warnings into exceptions.
